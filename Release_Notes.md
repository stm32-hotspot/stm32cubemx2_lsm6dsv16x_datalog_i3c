# Release Notes for <mark>stm32cubemx2_lsm6dsv16x_datalog_i3c</mark>

# Purpose

This example demonstrates how to use the LSM6DSV16X part driver with STM32CubeMX2 on I3C bus with SETDASA.

## Main changes

### First release

Initial release of the lsm6dsv16x_datalog_i3c example for STM32CubeMX2.

## Known limitations

No limitation raised for this example.

## Dependencies

Configuration and code generation features require STM32CubeMX2 >= 1.1.0.
